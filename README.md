# OZUA Consultoria Website

Website single page para o centro de formação profissional Ozua, 
este projeto foi a reconstrução de um site que não foi lançado com a melhoria de alguns de detalhes,
o design foi criado por outro indivíduo.

## Tecnologias

-  HTML, CSS e JS

## Como executar

1. Clicar no ficheiro HTML

## Estrutura principal

```text
index.html     Página única
css/           Ficheiros de estilização
js/            Ficheiros JS
assets/        Fontes, ícones e imagens
```
